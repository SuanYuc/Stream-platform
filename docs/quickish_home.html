Publish from your terminal

One command, anywhere you code.

Prefer the shell? Point the CLI at a folder of HTML and it’s live in seconds. No build step, no config, no server. Perfect for coding agents and AI assistants that work in a terminal.

terminal
$ npm i -g quickish
$ quickish
✓ live · you.quickish.site

Localish New

Your localhost, live at a private URL.

Run quickish --localish and your running dev server gets a stable, private, sign-in-gated Quickish URL, hot reload and all. No deploy, no third-party tunnel, nothing exposed to the public web. Share a work-in-progress, or hand a coding agent a link to watch its own changes land.

terminal
$ quickish --localish
● tunneling localhost:5173
✓ live · you.quickish.site/_localish/app/

Develop offline New

Build the whole app on your machine.

quickish dev runs your entire backend locally, quick.db, quick.sql, server functions, file uploads, even the signed-in user, with no account and no network. Build and test the real thing offline, snapshot your data as you go, then publish it unchanged. Made for AI agents working in a sandbox.

terminal
$ quickish dev
● quick.db · quick.sql · quick.fn · files
✓ localhost:4321 · no account, no network
