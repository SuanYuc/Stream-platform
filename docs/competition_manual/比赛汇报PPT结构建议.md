# 比赛汇报 PPT 结构建议

## 1. 项目定位

- 标题：AI 智能增强导播平台
- 一句话定位：将导播台基础工作流、语义智能导播、实时智能滤镜、无限画布和云推流整合为一体化直播制作系统。
- 配图：主界面全景截图。

## 2. 痛点与目标

- 传统导播软件学习成本高，复杂场景编排不直观。
- 普通直播工具缺少智能推荐、智能滤镜和云端发布链路。
- 本项目目标：提升导播效率、降低节目事故风险、增强画面表现力、支持云端分发。

## 3. 总体架构

- 展示本地导播台、AI 模型、渲染合成、音频调音台、云推流服务之间的数据流。
- 配图：手册中的 Mermaid 架构图可重绘为 PPT 流程图。

## 4. 基础导播功能

- 场景九宫格。
- 多源输入：摄像头、屏幕、窗口、网络流、图片、视频。
- 图层优先级、位置大小、锁定、隐藏。
- Preview / Program 双画面。
- 推流、录制、转场、紧急占位。

## 5. 智能导播功能

- 中文语义输入。
- FG-CLIP2 图文向量匹配。
- 场景推荐与相似度排序。
- 当前采用推荐模式，避免误切。

## 6. 智能滤镜功能

- 基础色彩滤镜。
- MediaPipe 虚拟背景。
- MediaPipe AR 贴纸。
- ONNX 卡通化、莫奈、梵高风格迁移。
- GPU 优先与本地降级。

## 7. 无限画布功能

- 场景作为集合框。
- 图层作为基本对象。
- 自由拖拽、缩放、组合。
- 图层可拖入/拖出场景框。
- 画布内容可写回已有场景或保存为新场景。

## 8. 音轨调音台

- 系统音、窗口音轨、麦克风、总音轨。
- 音量、静音、低中高频、实时声纹。
- 给后续智能降噪、违禁词检测预留接口。

## 9. 云推流功能

- 本地 Program 输出 RTMP。
- 云服务器 MediaMTX 接收。
- Go API 管理 URL 与转推。
- HLS/RTMP 播放与阿里云直播转推。

## 10. 技术亮点与创新

- 图层级 AI 视觉处理链。
- 语义导播推荐。
- 无限画布编排。
- 音轨化音频架构。
- 本地制作与云端分发解耦。

## 11. 演示流程

- 添加输入源。
- 调整图层。
- 开启智能滤镜。
- 输入语义推荐场景。
- 无限画布编排并写回。
- 开始云推流。
- 触发紧急占位。

## 12. 后续规划

- 智能导播脚本模式。
- YOLO + CLIP 多模型融合。
- 智能音频模型。
- 云端监控面板。
- 画布模板和 AI 自动布局。
