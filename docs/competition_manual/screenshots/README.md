# 截图采集清单

把真实截图保存到本目录，文件名与主手册保持一致。

## 必备截图

1. `01_main_console.png`
   - 主界面全景：场景九宫格、编辑预览、节目输出、推流录制控制、音轨选择。

2. `02_scene_layer_control.png`
   - 图层管理子界面：添加源、图层优先级、滤镜、音频、色彩校正、智能增强按钮。

3. `03_semantic_director.png`
   - 语义智能导播：输入中文语义、推荐场景、相似度、推理设备、耗时。

4. `04_smart_filters.png`
   - 智能滤镜效果：虚拟背景、AR 贴纸、ONNX 卡通化/莫奈/梵高风格。

5. `05_infinite_canvas.png`
   - 无限画布：坐标网格、场景框、图层对象、折叠场景/图层列表、属性/特效入口。

6. `06_cloud_streaming.png`
   - 云推流：本地 RTMP 地址、云服务器服务状态、HLS 播放验证或 API health 返回。

## 截图建议

- 截图尺寸建议 1920x1080 或主窗口完整尺寸。
- 参赛文档中建议隐藏服务器密码、API Token、AccessKey 等敏感信息。
- 对 AI/ONNX 功能截图时，尽量准备对比明显的图片或摄像头画面。
- 云推流截图建议包含“本地开始推流”和“云端播放成功”两个证据。
